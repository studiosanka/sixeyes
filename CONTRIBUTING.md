# SixEyes — Usage & Contribution Policy

## Licences

SixEyes uses three licences:

| Files | Licence |
|---|---|
| Firmware and software (`firmware/`, `hardware/tools/`) | Apache 2.0 — see `LICENSE` |
| Hardware design files (`hardware/`) | CERN-OHL-S-2.0 — see `hardware/LICENSE` |
| Documentation (`docs/`) | CC-BY-4.0 — see `docs/LICENSE` |

## Using the Firmware

The firmware is licensed under Apache 2.0. You are free to use, modify, and incorporate it into your own projects, including commercial and closed-source products, subject to the Apache 2.0 terms.

## Using the Hardware Designs

The hardware design files (KiCad schematics, PCB layouts, Gerbers, STL files) are licensed under CERN-OHL-S-2.0 (Strongly Reciprocal). In plain terms:

- You are free to build, modify, and manufacture hardware from these designs.
- If you distribute or sell products based on these designs, you must:
  - Make the complete design source files publicly available under the same licence.
  - Retain all copyright and attribution notices — including the Studio Sanka copyright — in the design files and any accompanying documentation.
- Derivative hardware designs must also be released under CERN-OHL-S-2.0.

We additionally ask — as a community norm — that any manufactured or sold product visibly credit **Studio Sanka** on the product, packaging, or product listing.

The KiCad library in `hardware/pcb/libraries/lcsc_parts/` contains symbols, footprints and 3D models converted from third-party component libraries. They are not covered by our licence, and we have not verified their terms; see the README in that folder.

## Using the Documentation

The documentation is licensed under CC-BY-4.0: you may share and adapt it, including commercially, as long as you give appropriate credit to Studio Sanka and indicate if you made changes.

## Contributions

This repository is maintained exclusively by Studio Sanka members. We are not accepting pull requests or external contributions at this time.

## Feedback & Feature Requests

If you have feedback, found a bug, or want to suggest a feature, open an issue at https://github.com/studiosanka/sixeyes/issues or find us via our Studio Sanka page. We read everything, though we cannot guarantee a response to every message.
