# Datasheets and links

Manufacturer pages for the main parts. We link to them instead of storing copies of the PDFs here.

| Part | Where to find it |
|---|---|
| TMC2209 stepper driver | [Analog Devices (Trinamic) product page](https://www.analog.com/en/products/tmc2209.html), which has the datasheet. The old Trinamic address redirects there. |
| AS5600 magnetic encoder | [Datasheet (PDF, hosted by Infineon)](https://www.infineon.com/assets/row/public/documents/24/49/infineon-as5600-datasheet-en.pdf) |
| ESP32-C6 | [Espressif product page](https://www.espressif.com/en/products/socs/esp32-c6) |
| LM2940 5 V regulator | [Texas Instruments product page](https://www.ti.com/product/LM2940-N) |
| XL4016E1 buck regulator | [LCSC product page (datasheet link on the page)](https://www.lcsc.com/product-detail/C55881.html) |
| MCP2562 CAN transceiver | [LCSC product page (datasheet link on the page)](https://www.lcsc.com/product-detail/C640345.html) |
| M3 hex standoffs (Shuntian) | [LCSC product page for the 8 mm part, C551328](https://www.lcsc.com/product-detail/C551328.html); the datasheet there covers the whole M3 x 3 to 30 mm family |

Every other part in the [bill of materials](../../hardware/pcb/bom/v1.2_BOM_LCSC.csv) has its LCSC part
number in the first column. Search that number on [lcsc.com](https://www.lcsc.com) for its page and datasheet.
