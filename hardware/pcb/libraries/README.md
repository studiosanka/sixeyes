# KiCad libraries

The KiCad project in `../kicad/` finds these libraries through its `fp-lib-table` and `sym-lib-table`
(paths are relative to the project, so nothing needs to be installed or configured).

| Folder | What it is |
|---|---|
| `lcsc_parts/` | Symbols, footprints and 3D models of the LCSC parts used on the board (library name `SixEyes_v1.2`). |
| `SixEyes_custom/` | Parts we drew ourselves: the AS5600 encoder module, the NEMA17 motor (mechanical outline) and the M3x8 standoff (library name `SixEyes_custom`). Generated by `../../tools/add_custom_parts.py`. |
| `source_models/` | The source STEP models the generator reads. |

## About `lcsc_parts/`

These were converted from the EasyEDA/LCSC component library with
[easyeda2kicad](https://github.com/uPesy/easyeda2kicad) (v1.0.1), using the LCSC part numbers in
`../bom/v1.2_BOM_LCSC.csv`. Only the parts used by the board are included.

**Licence note:** the symbols, footprints and 3D models come from third-party libraries. We have not
verified their licence terms. They are included so that the board opens without extra setup. If you reuse
them elsewhere, check the terms for each part. To regenerate a part yourself:

```
pip install easyeda2kicad
easyeda2kicad --full --lcsc_id=C55881 --output my_parts
```

Each footprint has a `.wrl` model (what KiCad shows). A `.step` copy is included only for parts placed on
the board, so you can export the whole board to STEP.
