# Signed drawings, v1.2

Release documents for the joint board, on the Studio Sanka drawing sheet (A3). Both are **drawn and approved by Vincent Santosa**. The schematic was signed on 21 Oct 2026; the layout plot was re-signed on 22 Oct 2026 after the terminal pinouts were added to the silkscreen.

| Document no. | File | What it is |
|---|---|---|
| SXE-PCB-v1.2-SCH | [SXE-PCB-v1.2-SCH.pdf](SXE-PCB-v1.2-SCH.pdf) | The signed schematic (one A3 sheet). It is a picture of the sheet, so you cannot select its text. |
| SXE-PCB-v1.2-GBR | [SXE-PCB-v1.2-GBR.pdf](SXE-PCB-v1.2-GBR.pdf) | The signed layout, plotted layer by layer (10 pages) from KiCad. |

These are for **reading and review**. The files you send to a PCB manufacturer are the Gerber and drill files in [`../gerbers/`](../gerbers/), and the editable design is in [`../kicad/`](../kicad/).

The sheet itself (title block, licences and logo) is `Studio Sanka KiCad Sheet.kicad_wks` in [`../kicad/`](../kicad/).
